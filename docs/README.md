# 测试文档索引

本目录保存学习协作系统的软件测试分析、测试用例、执行报告、缺陷记录和正式截图证据。当前公开基线共执行 **124** 条场景：**Pass 77、Fail 37、Risk 10**；累计记录 **21** 个已确认缺陷、**1** 个业务规则缺口和 **9** 个风险候选。

> 结果口径：只有已经实际执行并有记录的场景才计入统计。源码预测、需求待确认项和已确认缺陷分别标注，不互相替代。

## 推荐阅读顺序

1. 先阅读仓库根目录的 [作品集 README](../README.md)。
2. 阅读 [测试分析](./test-analysis.md) 了解系统和覆盖范围。
3. 阅读 [缺陷报告](./bug-report.md) 查看高价值问题。
4. 从任务、讨论、文件或管理员执行报告中选择一个模块查看完整证据链。
